# Modelagem de dados

Esta pasta reúne o diagrama entidade-relacionamento do projeto.

O DER representa os relacionamentos lógicos identificados durante a auditoria. Como as tabelas de origem não possuíam chaves estrangeiras físicas, o diagrama documenta relações inferidas a partir das referências validadas, e não constraints implementadas no banco.

- imagem de visualização `.png`
